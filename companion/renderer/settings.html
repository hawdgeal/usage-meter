Usage Meter Companion

Browser connection

Usage comes from the Usage Meter extension in your browser, using your existing sign-in. The browser needs to be running; the Claude and ChatGPT tabs don't need to be open. To do without the browser, sign in here instead (below).

Then reload the extension (or restart the browser).
Extension not found?

Chrome, Edge and other Chromium browsers only let listed extensions talk to this app. Installed copies are found automatically. If yours isn't, copy its ID from the browser's extensions page (turn on Developer mode) and add it here. Firefox needs no ID.

    Sign in here (no browser needed)

    Sign in to Claude or ChatGPT in the companion itself, and it fetches your usage on its own, so the browser doesn't need to be running. You sign in on the site's own page; the companion keeps that login on this computer and only contacts claude.ai and chatgpt.com. When the extension reports newer numbers, those are used.

    Updates

    Updating downloads the new version from the project's GitHub releases, replaces the app's files and restarts it. Your settings stay. Update the browser extension separately.
