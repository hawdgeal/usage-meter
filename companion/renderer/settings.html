Usage Meter Companion

Browser connection

Usage comes from the Usage Meter extension in your browser, using your existing sign-in. The browser needs to be running; the Claude and ChatGPT tabs don't need to be open.

Then reload the extension (or restart the browser).
Extension not found?

Chrome, Edge and other Chromium browsers only let listed extensions talk to this app. Installed copies are found automatically. If yours isn't, copy its ID from the browser's extensions page (turn on Developer mode) and add it here. Firefox needs no ID.

    What to show

    Look and layout

    The panel looks and behaves like the one in your browser: theme, bar colors, spacing, compact mode, module order, hover options and width all come from the extension's settings for each site. Change them under Customize in the browser panel; the companion updates within a few seconds. Collapsing the panel or its sections here only affects the companion.

    Mini panel

    Drag it by any part that isn't a button. Right-click it for options. Separate cards each have their own position and pin.
